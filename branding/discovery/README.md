# Discovery

Drafts for getting Simple Shot Timer listed outside the two app stores, so
people and AI search find it. Nothing here is part of the app or the website.

| File | What it is |
|---|---|
| [fdroid.md](fdroid.md) | F-Droid eligibility check, how to submit, what each release needs, and IzzyOnDroid as the faster alternative |
| [cc.jami.simpleshottimer.yml](cc.jami.simpleshottimer.yml) | Draft fdroiddata metadata (the file for `metadata/` in a fork of fdroiddata) |
| [wikidata.md](wikidata.md) | Draft Wikidata item: statements with their properties, references and a QuickStatements batch |

The F-Droid listing texts, icon, feature graphic, screenshots and changelogs
live in `fastlane/metadata/android/`, together with the Play listing texts.
